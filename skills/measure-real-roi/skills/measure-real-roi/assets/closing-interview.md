# Closing Interview

1. Review the participant's records together.
2. Correct any values that look wrong in hindsight.
3. Ask what the numbers left out.
4. Ask whether any result depended on a process change as well as the tool.
5. Ask how taking part felt.
6. Ask whether the participant would keep using the measurement method.
7. Record any correction as a new confirmed value, not as a silent edit.
