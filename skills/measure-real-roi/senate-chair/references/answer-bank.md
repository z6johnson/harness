# Senate Chair Answer Bank

Entries are the Chair's approved answers. Do not edit an answer without Chair approval. The bank is currently empty: paste the approved answers from the planning conversation using the entry format below. An empty bank means every reply request is "no match" — offer the closest entries and routing, and never improvise policy.

## Entry format

```markdown
## <Topic title>
- ID: SC-001
- Triggers: <phrases faculty actually use when asking this>
- Status: approved
- Last reviewed: YYYY-MM-DD
- Answer:

<approved answer, verbatim>

- Routing: <office or person to cc or defer to, if any>
- Cautions: <situations where this answer does not apply>
```

## Rules

- Transfer each approved answer verbatim, one entry per answer.
- Use stable IDs: SC-001, SC-002, and so on.
- List 2-4 trigger phrasings per entry, drawn from how faculty actually ask.
- Set `Last reviewed` to the date the Chair approved the answer.
- Fill `Routing` and `Cautions` only where they genuinely apply.
